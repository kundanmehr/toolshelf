Common questions

What is the difference between HEX and RGB?

They describe the same color. HEX writes the red, green and blue values in base 16, for example #2F5BFF, while RGB writes them as numbers from 0 to 255.

When should I use HSL?

HSL (hue, saturation, lightness) is easier to adjust by hand, for example to make a color lighter or less intense.
