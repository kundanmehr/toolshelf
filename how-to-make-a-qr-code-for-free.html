How to Make a QR Code for Free (No App Needed)

Create a free QR code for a link, text or Wi-Fi details in under a minute, and learn how to make sure it scans every time.

You do not need an app, an account or a subscription to make a QR code. A free generator that runs in your browser is enough, and the result can be printed on a menu, a flyer, a business card or a shop window.

Make one in four steps

  1. Open the generator. Go to the free QR code tool on this site.
  2. Type or paste your content. This is usually a web address, but plain text works too. Always include the full address, starting with https://.
  3. Check the preview. The code appears as you type.
  4. Download it as an SVG. SVG is a vector format, so it stays sharp whether it is the size of a stamp or a poster.

Make sure it scans every time

  • Test before you print. Scan it with your own phone, and ideally a second phone, before printing a hundred copies.
  • Keep strong contrast. Dark code on a light background is the safest choice. Light code on a dark background fails on some scanners.
  • Leave a blank border. The empty margin around the code helps scanners find it, so do not crop it or place text against its edge.
  • Do not print it too small. As a rough rule, aim for at least 2 cm (about 0.8 inch) wide, and bigger if people will scan from a distance.
  • Prefer short links. A shorter address makes a simpler code that is easier to scan.

Will it expire?

A static QR code, like the ones made here, holds your text directly inside the pattern. It has no tracking link and no expiry date, so it keeps working as long as the web address it points to keeps working. Some paid services create dynamic codes that pass through their own server, and those can stop working if you stop paying.

One safety tip

Anyone who scans the code can read what is inside it, so never put passwords or private information in a QR code you plan to display in public.
