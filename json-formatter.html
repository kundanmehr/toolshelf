JSON Formatter

Check, format or compact JSON.

How to use the json formatter

Paste JSON, then choose Format to indent it or Compact to remove spaces. If the JSON is invalid you will see the error message.

Common questions

Why does my JSON say invalid?

The most common causes are trailing commas, single quotes instead of double quotes, and keys without quotes.

Is my JSON sent to a server?

No. It is parsed in your browser, so private data stays on your device.
